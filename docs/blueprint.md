# **App Name**: FormaText

## Core Features:

- Formatted Text Editor: Clean, minimal interface with syntax highlighting for Markdown and reStructuredText in an editable source view.
- Real-time Live Preview: Dynamically rendered HTML preview in a split-view panel, synchronized with the editor's cursor position.
- Rich Content Support: Comprehensive rendering of GitHub-flavored Markdown (tables, task lists) and LaTeX math via MathJax for both editor and preview.
- AI Writing Enhancer: An intelligent tool that suggests context-aware completions, summaries, or rephrasing based on selected text within the editor.
- High-Fidelity Document Export: Generate high-quality PDFs with preserved formatting, fonts, math, and hyperlinks, and export to HTML with optional CSS embedding, respecting user-defined margins, page size, and orientation.
- Document Outline Navigation: Dynamic table of contents (TOC) sidebar for quick navigation within long documents.
- Auto-Save & Local Persistence: Automatically saves document changes to the local file system at regular intervals and supports encoding detection (e.g., UTF-8) and line ending options.

## Style Guidelines:

- Primary color: A professional and calming blue (#2966A3) to highlight active states and key interface elements.
- Background color: A very light, desaturated blue-gray (#F1F5F7) for a clean, focused editing canvas, minimizing visual distraction.
- Accent color: A vibrant yet sophisticated aqua (#26D9D9) to draw attention to interactive elements, alerts, or specific actions.
- Default body and headline font: 'Times New Roman' (serif), as requested by the user, for a classic and readable appearance in both editor and preview. Note: currently only Google Fonts are supported.
- Code block font: 'Fira Code' (monospace) for clear, distinguishable display of code snippets. Note: currently only Google Fonts are supported.
- Responsive split-view layout with the editable source on the left and live preview on the right, designed for desktop environments with configurable sizing.
- Minimalist, clean outline icons for core functionalities to maintain a modern and uncluttered user interface.
- Subtle and swift animations, such as fades and smooth transitions, to enhance user interaction without being distracting.
