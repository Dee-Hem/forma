# FormaText

**FormaText** is a lightweight, browser-based editor for creating and formatting **Markdown** and **reStructuredText** documents with a live preview.

It is designed to provide a simple writing environment while still offering useful tools for technical and structured documentation.

## ✨ Features

* 📝 **Markdown Editor** — Write and format Markdown documents.
* 📚 **reStructuredText Support** — Create documents using reStructuredText syntax.
* 👀 **Live Preview** — See how your document renders while you write.
* 🤖 **AI Writing Assistant** — Get assistance while drafting and editing content.
* 📄 **PDF Export** — Export finished documents as PDF files.
* 🧭 **TOC Navigation** — Automatically navigate through document headings.
* 🧮 **Math Support** — Write mathematical expressions using LaTeX.
* 🔤 **UTF-8 Support** — Work with a wide range of characters and languages.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/formatext.git
cd formatext
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Then open the local development URL provided by your framework.

## 💡 Why FormaText?

Technical documentation often requires more than a basic text editor. FormaText brings structured writing, live rendering, mathematical notation, and document export into one workspace.

The project was built to explore the development of practical productivity tools while working with structured text formats and browser-based interfaces.
